# covid-lethality

## РУКОВОДСТВО НА РУССКОМ
Краткая сводка о функциях программы и общей сути.

Цель программы вычислить выживаемость человека, переболевшего COVID-19, основываясь на таких характеристиках:

Тромбоцитарные параметры:

    PLT: общее количество тромбоцитов (10^9/л)
    MPV: средний объем тромбоцита (фемтолитр)
    PDW: ширина распределения тромбоцитов (фемтолитр)
    PCT: тромбокрит (%)

Эритроцитарные параметры:

    RBC: общее количество эритроцитов (10^12/л)
    HGB: уровень гемоглобина (г/л)
    MCV: средний объем эритроцита (фемтолитр)
    MCH: содержание гемоглобина в эритроците (пикограмм)

### FUNCTIONS
"OPEN CSV/XLSX" кнопка, которая загружает файл в программу, который вы хотите обработать.

"PROCESS FILE" кнопка, которая вычисляет данные из файла.

"SAVE FILE" кнопка, которая сохраняет полученные данные в новой таблице

## ENGLISH MANUAL
Here's the quick rundown of this app's functions and general purpose.

The app's aim is to calculate the survivability of a person, who had COVID-19, based on their characteristics:


Platelet Parameters:

    PLT: Total platelet count (10^9/L)
    MPV: Mean platelet volume (femtoliter)
    PDW: Platelet distribution width (femtoliter)
    PCT: Plateletcrit (%)

Erythrocyte Parameters:

    RBC: Total erythrocyte count (10^12/L)
    HGB: Hemoglobin level (g/L)
    MCV: Mean corpuscular volume (femtoliter)
    MCH: Mean corpuscular hemoglobin (picogram).

### FUNCTIONS
"OPEN CSV/XLSX" button is to upload the files that you wish to parse and get the data out of.

"PROCESS FILE" button is to start processing the data inputted from the table.

"SAVE FILE" button is to save the data that is processed out of your table.
